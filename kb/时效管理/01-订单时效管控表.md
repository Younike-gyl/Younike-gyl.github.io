# 订单时效管控表

## 1. 背景

订单时效是供应链服务水平的关键衡量指标。建立标准化的时效管控表，有助于识别各环节瓶颈，提升履约能力。

## 2. 时效节点定义

```
订单创建 → [T+0] → 订单审核 → [T+0.5] → 库存分配 → [T+1] → 拣货出库 → [T+1.5] → 物流揽收 → [T+2~T+5] → 末端配送 → 签收
```

| 节点编号 | 节点名称 | 标准时效 | 责任部门 | 关键动作 |
|:--------:|----------|:--------:|----------|----------|
| N1 | 订单审核 | 4h | 销售客服 | 核对订单信息、客户信用 |
| N2 | 库存分配 | 2h | 仓储 | WMS自动分配库位 |
| N3 | 拣货出库 | 4h | 仓储 | 波次拣货、复核包装 |
| N4 | 物流揽收 | 4h | 物流 | 承运商取件扫描 |
| N5 | 干线运输 | 24~72h | 物流 | 中转分拨 |
| N6 | 末端配送 | 24h | 物流 | 派送签收 |

## 3. 管控指标

### 3.1 核心 KPI

| 指标 | 定义 | 目标值 | 监控频率 |
|------|------|:------:|:--------:|
| **当日达比例** | 当日出库订单占比 | ≥ 85% | 每日 |
| **48 小时签收率** | 下单后 48h 内签收比例 | ≥ 75% | 每日 |
| **超时订单数** | 任一节点超时的订单数 | ≤ 50 单/日 | 每日 |
| **订单履约周期** | 下单到签收的平均耗时 | ≤ 72h | 每周 |

### 3.2 预警规则

> 系统应根据以下规则自动触发预警通知。

- **黄色预警**：任一节点耗时超过标准时效的 **80%**，发送企业微信提醒
- **橙色预警**：任一节点耗时超过标准时效的 **100%**，升级至主管
- **红色预警**：订单整体超时 **24h** 以上，升级至部门负责人

## 4. 异常原因分类

| 原因类别 | 典型场景 | 责任方 |
|----------|----------|:------:|
| 库存不足 | 系统显示有库存但实物短缺 | 仓储 |
| 拣货错误 | 拣错 SKU、数量不符 | 仓储 |
| 物流延误 | 天气、交通、运力不足 | 物流承运商 |
| 系统异常 | WMS/OMS 接口超时 | IT |
| 客户原因 | 地址不详、电话不通 | 客户/客服 |

## 5. 改善措施清单

1. **库存盘点**：每周循环盘点 A 类 SKU，确保库存准确率 ≥ 99%
2. **波次优化**：按区域合并波次，减少拣货路径
3. **承运商考核**：月度评比承运商时效表现，末尾淘汰
4. **预包机制**：爆款 SKU 提前预包装，订单下达后直接贴单出库
5. **系统监控大屏**：实时展示各节点时效数据，异常自动高亮
