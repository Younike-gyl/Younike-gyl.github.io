# 收货入库流程

## 1. 目的

规范仓库收货入库操作，确保入库物料**数量准确、质量合格、单据齐全**，实现入库全流程可追溯。

## 2. 适用范围

适用于公司所有原材料、半成品、成品及客供品的入库操作。

## 3. 职责分工

| 角色 | 职责 |
|------|------|
| 仓管员 | 收货核对、数量清点、系统录入、实物上架 |
| 质检员 | 来料检验、出具检验报告、判定合格/不合格 |
| 采购员 | 供应商对接、不合格品退换货协调 |
| 财务 | 发票核对、入库单审核、账务处理 |

## 4. 操作流程

### 4.1 到货接收

1. 供应商送货至仓库指定卸货区
2. 仓管员核对 **送货单** 与 **采购订单（PO）** 信息：
   - 供应商名称
   - 物料编码
   - 规格型号
   - 数量
3. 外观初检：检查外包装是否完好，有无破损、潮湿、变形

### 4.2 数量清点

- 整箱物料：按箱数清点后，**按比例抽检**（一般不低于 10%）
- 散件物料：**逐件清点**，记录实际数量
- 称重类物料：过磅称重，与送货单重量比对，**误差 > 0.5% 时需复磅**

### 4.3 质量检验

质检员按《来料检验标准》执行：

```
检验等级：正常检验（GB/T 2828.1）
AQL 值：致命缺陷 0、严重缺陷 0.65、轻微缺陷 1.5
抽样方案：一次抽样
```

检验结论分三类：

| 结论 | 处置方式 |
|------|----------|
| 合格 | 入库上架 |
| 让步接收 | 经技术/质量负责人签字确认后入库，标注让步标识 |
| 不合格 | 隔离存放于不合格品区，通知采购员安排退货 |

### 4.4 系统入库

1. 仓管员在 ERP 系统中录入入库信息
2. 关键字段：
   - **入库单号**：系统自动生成（如 RK-20260728-001）
   - **入库日期**：实际入库日期
   - **库位编号**：如 A-01-03（货架A-层01-列03）
3. 打印入库单，经仓管员签字后存档

### 4.5 实物上架

- 遵循 **先进先出（FIFO）** 原则，新批次物料放在旧批次后面
- 库位更新：扫码确认库位，确保系统库位与实物一致
- 悬挂 **物料标识卡**：注明物料名称、批次号、入库日期、数量

## 5. 异常处理

> 异常情况须在 30 分钟内上报仓库主管，并填写《异常处理记录表》。

| 异常类型 | 处理措施 |
|----------|----------|
| 实收数量 < 送货单数量 | 按实收数量签收，送货单备注实收数，双方签字确认 |
| 外包装破损 | 拍照留证，开箱逐件检查，破损件拒收 |
| 物料规格不符 | 拒收全批，通知采购员与供应商确认 |
| 送货单与 PO 不一致 | 暂停收货，待采购员核实后再处理 |

## 6. 关键绩效指标（KPI）

- **入库及时率**：到货后 2 小时内完成系统入库的比例 ≥ 95%
- **入库准确率**：入库数量与实收数量一致的比例 ≥ 99.5%
- **质检及时率**：来料后 4 小时内完成检验并出具报告的比例 ≥ 90%
